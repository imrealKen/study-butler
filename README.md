# Study Butler · 课程学习管家

一个给 Codex 用的中文学习管家技能。它把你的学期计划变成可执行的每日任务：
读计划 → 算剩余天数 → 派当天学习块 → 记录进度，并且在讲知识点之前强制先要课程材料。

最初为西交利物浦大学 2026-27 S1 设计，规则本身与学校无关，任何按周排课的专业都能用。

## 它解决什么问题

- 学期的 DDL 散在 handbook、课程页、任务书里，容易记混日期
- 知道「有作业」但不知道今晚该做哪一件
- 计划写完就躺在文件夹里，没人跟进
- 让 AI 讲课，它容易脱离课件自由发挥

## 三条硬规则

1. 全程中文，术语保留英文
2. 讲之前先要材料，没材料不凭空讲
3. 一次只推进一个概念，讲完要求复述

## 安装

把 `SKILL.md` 放到 Codex 的技能目录：

```
~/.codex/skills/study-butler/SKILL.md
```

Windows 上是 `C:\Users\<你>\.codex\skills\study-butler\SKILL.md`。

## 配置

在技能目录下放两个文件，或修改 `SKILL.md` 里「数据源」一节指向你自己的路径：

**study-plan.md** —— 学期主计划

```markdown
## DDL 总表

| 截止时间 | 课程 · 事项 · 权重 | 备注 |
|---|---|---|
| 2026-12-09 23:59 | ISA305 Assessment 2 · 10% | 课程页 |

## 周计划

### W10｜11/16–11/22

| 时间 | 任务 | 时长 |
|---|---|---|
| 周三 11/18 晚 | 把 10 次 lab 映射到报告章节 | 2h |
```

**study-log.md** —— 进度记录，只追加

```markdown
| 日期 | 时长 | 任务 | 状态 | 备注 |
|---|---|---|---|---|
| 2026-11-09 | 2h | 转录起始 | 完成 | 自测 3 题待回看 |
```

## 用法

直接说人话就行：

- 「今天做什么」
- 「这周的 DDL 有哪些」
- 「今晚学什么」
- 「开始学，讲第三讲」

## 配成定时提醒

在 Codex 的 Automations 里建 heartbeat，提示词写成：

```
按 study-butler 技能执行：读 study-plan.md 和 study-log.md，换算今天属于第几周，
输出四段：今日一行、全部 DDL 表（含已完成和待公布）、各科进度、今晚 90 分钟清单。
距最近硬截止 ≤3 天时只派该截止相关任务。
```

一个容易踩的坑：调度的 `RRULE` 按 **UTC** 解释 `BYHOUR`。
想要北京时间 19:30，写 `BYHOUR=11;BYMINUTE=30`；想要 08:30，写 `BYHOUR=0;BYMINUTE=30`。

## 设计取舍

- **先要材料再讲**：没有课件的讲解会变成通用科普，考试不考那个。
- **进度写文件而不是记在对话里**：换对话、隔两周回来，状态还在。
- **按分数杠杆排序而不是按截止日期**：到期早的低权重任务会吃掉高权重任务的准备时间。
- **记录里没有就写「无记录」**：不替用户假设「应该做完了」。
